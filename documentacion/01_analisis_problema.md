Programa de recomendación de películas por medio de aplicación de álgebra lineal.

Este fué mi proyecto para la asignatura de álgebra lineal, y consiste en un programa al que puedas ingresar y que por medio de puntajes que tu le des al programa, a géneros de películas y as una lista de películas base, te de recomendaciones de películas nuevas para ver.

Entradas:
La entradas que se usaron en este programa son:
Nombre del usuario -> boleano
Calificación asignada a cada género de película -> número entero del 0 al 5
Calificación asignada a cada película base. -> número entero del 0 al 5

Las restricciones serán que no puedas ingresar número en el apartado del nombre de usuario, y en el caso de las calificaciones, que no puedas elegir un número fuera del rango de 0 a 5.

Procesos:
El proceso que sigue este programa es, recibe la entrada del nombre de usuario y las calificaciones que asigne a cada pregunta, y con ello devuelve la similitud coseno que tenga con los perfiles existentes para que te pueda recomendar nuevas películas.

Salidas esperadas:
Imprime en terminal el nombre de usuario y las películas que te recomienda ver.

Alcance:
La idea de este programa es que se pueda hacer una libreria de cientos de películas para que te pueda recomendar muchas que sean afines a tus gustos.
