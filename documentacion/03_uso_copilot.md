1.  ¿Cómo utilizaste las especificaciones para solicitar código a Copilot? 

Usando comentarios en el código, describiendo la funcionalidad que necesitaba y proporcionando ejemplos de entrada y salida cuando era necesario. Esto ayudó a Copilot a entender mejor el contexto y generar código más relevante.

2.  ¿Qué revisaste o modificaste del código generado? 

Revisé el código generado por Copilot para asegurarme de que cumpliera con los requisitos especificados. Realicé modificaciones en la lógica de algunas funciones y ajusté los nombres de las variables para que fueran más descriptivos.

3.  ¿Copilot generó una respuesta incorrecta o distinta de lo solicitado? Explica un caso si ocurrió. 

En el caso de la similitud coseno, solicité a Copilot que generara una función para calcular la similitud entre dos perfiles de usuario, pero el código generado no consideraba todas las variables relevantes. Tuve que ajustar la función manualmente para incluir todos los factores necesarios en el cálculo.

4.  ¿Cómo comprobaste el funcionamiento de clases y métodos? 

Implementé pruebas unitarias para verificar que cada clase y método funcionara como se esperaba. Estas pruebas incluían casos de prueba para entradas válidas e inválidas, asegurando que el código manejara adecuadamente diferentes escenarios.

5.  ¿Qué ventajas y limitaciones observaste? 

Ventajas:
- Ahorro de tiempo en la generación de código.
- Posibilidad de explorar diferentes enfoques y soluciones.
- Mejora en la calidad del código al recibir sugerencias de IA.


6.  ¿Por qué es necesario comprender código producido con ayuda de IA?

Es necesario comprender el código producido con ayuda de IA para poder realizar ajustes y mejoras en función de los requisitos específicos del proyecto. Además, la comprensión del código permite identificar posibles errores o limitaciones en las soluciones propuestas por la IA, asegurando que el producto final cumpla con los estándares de calidad y funcionalidad esperados.
